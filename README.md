# RoMaCS: Robust Maritime Channel Selection under Incomplete and Stale Observations

Code and benchmark for the paper:

> **Staleness-Aware Channel Selection with Conformal Abstention for Maritime IoT Networks**
> Jongkwan Lee and Minwoo Lee
> *Submitted to IEEE Internet of Things Journal.*
> [Paper DOI: TBA] · [Benchmark on IEEE DataPort: TBA] · [Archived release: TBA (Zenodo/Code Ocean DOI)]

RoMaCS formulates heterogeneous maritime channel selection (VHF-DSC, dPMR, AIS/VDES,
LTE/5G, satellite, plus an explicit `no_channel` fallback) as multi-class classification
under **partial and stale observability**, generalizing the binary missingness mask to a
per-channel **age of information (AoI)**. The framework pairs an age- and
missingness-aware representation and degradation-injected training of a tree-ensemble
core with a **Mondrian conformal abstention layer** that defers uncertain decisions with
a distribution-free, per-class coverage guarantee.

## Highlights

- **Physically motivated open benchmark**: 95,825 labeled scenarios from 4,800 vessel
  trajectories (8 seeds), generated by a link-budget chain (FSPL, over-sea shadowing,
  SINR, logistic PER, Shannon-capped throughput) with an oracle utility-policy labeler.
- **Robustness under missingness**: the learned selector retains macro-F1 0.946 at 75%
  missing QoS while the rule-based utility policy collapses from 1.000 to 0.532
  (Wilcoxon signed-rank, p = 0.0078 at every rate).
- **Robustness under staleness**: the age-aware selector stays at 0.956 when the mean
  telemetry AoI reaches ~7 decision epochs, while a staleness-blind learner falls to 0.546.
- **Selective prediction**: at 75% missingness, deferring 7.5% of decisions cuts the
  emergency-scenario error of committed decisions from 0.099 to 0.002 at 99.7% empirical
  coverage.

## Installation

Python ≥ 3.10. From the repository root:

```bash
pip install -r requirements.txt
```

## Quick start

Generate one seed of the benchmark and inspect it:

```bash
cd src
python romacs_datagen.py            # writes data/romacs_dataset_seed0_clean.csv + feature schema
```

Run the full missingness study (8 seeds, ~4 min on a single CPU core):

```bash
python romacs_experiment.py         # -> results/results_long.csv, summary CSVs, figures
```

Run the staleness sweep and the conformal abstention study:

```bash
python romacs_v2_experiment.py      # -> results/results_v2/*.csv
```

## Reproducing the paper

Every table and figure of the paper is produced by the scripts below (all seeds fixed;
outputs are deterministic up to library versions).

| Paper artifact | Script | Output |
|---|---|---|
| Benchmark + statistics (Sec. III) | `romacs_datagen.py` | `data/*.csv` |
| Macro-F1 vs missingness (Table "main"; Fig. degradation) | `romacs_experiment.py` + `topsis_baseline.py` | `results/results_long.csv`, `results/topsis_long.csv` |
| Tree vs non-tree, AUDC (Table "why trees") | `romacs_experiment.py` | `results/why_trees_tree_vs_nontree.csv` |
| Staleness sweep (Table/Fig. staleness) | `romacs_v2_experiment.py` | `results/results_v2/staleness_*.csv` |
| Conformal abstention (Table/Fig. abstention) | `romacs_v2_experiment.py` | `results/results_v2/abstention_*.csv` |
| Safety-critical + ablations A/B (Table "safety") | `romacs_experiment.py` | `results/ablation_*.csv` |
| Feature importances (Fig. importance) | `feature_importance.py` | `results/feature_importance.csv` |
| MAR robustness check (Fig. MAR) | `romacs_mar_check.py` | `results/mar_*.csv` |
| Inference latency (Table "latency") | `latency_benchmark.py` | `results/latency.csv` |
| All schematic/plot figures | `make_figures.py`, `make_figures_v2.py`, `fig1_redesign.py` | `figures/*.png` |
| Hyperparameter search (Appendix B) | `romacs_tuning.py` | `configs/tuned_configs.json` |

Or run everything in order:

```bash
bash scripts/reproduce_all.sh
```

The `results/` directory ships with the summary CSVs from the runs reported in the
paper, so reported numbers can be verified without re-running.

## Benchmark

The benchmark is fully synthetic but physically motivated: every QoS entry is derived
from a link-budget chain whose constants (path-loss exponents, over-sea shadowing,
noise floors, PER waterfall, rain fade) follow the cited ITU-R recommendations and
measurement studies (paper Appendix A). All constants are exposed in
`src/romacs_datagen.py` and can be replaced with measured values, after which the
benchmark regenerates unchanged — this is the intended path for calibration against
real maritime measurements. See `data/README.md` for the feature schema and the
IEEE DataPort record of the pre-generated CSVs.

## Requirements and runtime

All experiments run on a single commodity CPU core (no GPU). The full 8-seed
missingness study completes in minutes; the staleness + abstention study likewise.
Tested with Python 3.12, scikit-learn 1.8, imbalanced-learn 0.14, XGBoost 3.3,
SciPy 1.17, Matplotlib 3.10.
